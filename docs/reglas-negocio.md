# Reglas de negocio

| Código | Regla | Mensaje que ve el usuario |
|--------|-------|---------------------------|
| RN-01 | La fecha de salida debe ser posterior a la fecha de llegada. | "La fecha de salida debe ser posterior a la fecha de llegada." |
| RN-02 | La fecha de llegada no puede ser anterior a la fecha actual. | "La fecha de llegada no puede ser anterior a hoy." |
| RN-03 | El número de huéspedes debe ser mayor que cero. | "El número de huéspedes debe ser mayor que cero." |
| RN-04 | El número de huéspedes no puede superar la capacidad del alojamiento. | "Este alojamiento admite máximo X huéspedes." |
| RN-05 | El precio por noche debe ser mayor que cero. | "El precio por noche del alojamiento no es válido." |
| RN-06 | Una cotización solo se genera cuando las fechas ingresadas son válidas. | "Seleccione la fecha de llegada y la fecha de salida." |
| RN-07 | Una reserva solo se puede hacer después de generar una cotización válida. | El botón "Reservar" solo aparece después de cotizar. |
| RN-08 | La tarifa de servicio corresponde al 10 % del subtotal. | Se muestra como "Tarifa de servicio (10%)" en la cotización. |
| RN-09 | No se muestran los alojamientos marcados como inactivos. | La "Casa campestre" de Armenia no aparece en la lista. |
| RN-10 | Si una búsqueda no encuentra resultados se informa al usuario. | "No se encontraron alojamientos con esos filtros." |
